# arborae.github.io

Sito ufficiale di **Arborae** (GitHub Pages).  
Stack: **HTML + CSS** (zero build step).

## Deploy (GitHub Pages)

1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`

Il sito sarà disponibile su: `https://arborae.github.io`

## Personalizzazione rapida

- Logo: `assets/logo.svg` (sostituisci col tuo logo definitivo)
- Banner: `assets/banner.svg`
- Preview social: aggiungi `assets/social-preview.png` (1200×630) per preview perfetta

## Note

Landing pensata per essere dark-first, responsive e leggerissima.
